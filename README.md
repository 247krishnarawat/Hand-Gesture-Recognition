# 🤚 Hand Gesture Recognition using CNN

This project focuses on classifying hand gestures using the **LeapGestRecog dataset** from **Kaggle** with a custom-built **Convolutional Neural Network (CNN)** in TensorFlow/Keras.

---

## 📂 Dataset

- Dataset used: [Hand Gesture Recognition Dataset (LeapGestRecog)](https://www.kaggle.com/)
- It contains grayscale images of 10 gesture classes (`00` to `09`) collected from multiple users in different sessions.
- Used **up to 500 images per class** to manage training time and balance the dataset.
